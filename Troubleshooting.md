# Ticket Documentation

## Common Issues & Solutions

### Calendar Access  

**Solution:**  
- Approval from the appropriate person  
- Delegation access

**Procedure:**  
Outlook → File → Account Settings → Delegate Access → Add → [Name] → Add → OK → [Calendar, Tasks, Inbox, Contacts, Notes] → OK → OK

**Ticket Closure:**  
- Take a screenshot of the person's email approval.
- Attach the screenshot to the ticket.

### Monitor Request

**Solution:**  
- Email their manager
- Get approval
- Forward the email to the proper departement/team

**Ticket Closure:**  
- "monitor has been ordered/sent"
- Attach email approval

### File Restore

**Solution:**  
- Previous Versions

**Procedure:**  
[File's original location] → Previous Directory → Right Click on the actual folder → Properties → Previous Versions → Add file back

**Ticket Closure:**  
- "File has been restored"
- Tell the person
